# The floors scripts/mutation.sh holds each package to, one row a package: the
# package directory, its efficacy floor, its mutant coverage floor, and its
# least timeout coefficient. scripts/mutation.sh reads this file and nothing
# else for them. It refuses a package with no row, and ci/test-ci.sh fails on a
# package go list finds that has none, or a row that names no package. A
# package .gremlins.yaml excludes whole (internal/heapcap, extracttest,
# coretest) has no row. A new package adds its row here, and edits no other
# list.
#
# A floor may only rise. ci/test-ci.sh fails on a figure lower than the same
# row's at the release tag before HEAD, from the first release tag that holds
# this table (v0.2.3); before that tag the comparison is skipped. In CI a clone
# with no release tag fails it; outside CI, as in the suite runner's pod, it is
# skipped.
#
# A lowering the owner approved passes when the comment line directly above the
# row names the tag's row and the new row, three figures each, and the reason:
#   # lowered from 85 80 5 to 85 72 5 by owner 2026-11-02: <why>
# It excuses exactly that change of that row: a further drop, a drop in another
# column, or the same line left in place after the next tag carries the new row
# is not excused. This is the one place the line's form is written out.
#
# A figure at or below its floor fails. Efficacy is 85 for every package.
# Mutant coverage is 85 but where Go's coverage profile cannot see a test reach
# a mutant: it leaves package-level declarations and code after a statement's
# first func literal outside every block, so their mutants always read as not
# covered, however the tests run them. Such a package's floor is its measured
# figure rounded down, and one under it when the figure is whole. Case
# expressions no longer count against a package: since #209 scripts/mutation.sh
# covers one whose clause body ran (scripts/casecover), so a measurement before
# 2026-10-30 counts case expressions among its mutants not covered, and one
# from that day on runs them.
#
# The least coefficient is .gremlins.yaml's 5 but where a package's tests wait
# longer than the limit floor of 10 s per mutant allows for; the comment above
# such a row gives the measurement.
#
# The comments hold each package's last measurement, scoped alone: its mutant
# coverage, the mutants not covered (each a blind spot of the profile, unless
# it says otherwise) and its efficacy, with the date. A dry run (gremlins
# unleash --dry-run) counts a mutant that would not compile as runnable, so its
# figure is an upper bound. The packages with no comment were not measured
# alone since the floors went per package.
#
